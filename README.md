# Python Quiz Application

## Project Description
A simple console-based quiz application developed using Python.

## Features
- Multiple-choice questions
- Four options for each question
- Automatic answer checking
- Score calculation
- Percentage calculation
- Performance feedback
- Play again option

## Concepts Used
- Python Functions
- For Loop
- While Loop
- If-Else Statements
- Variables
- Input and Output

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the command:

python quiz.py
